# Bank-management-project
# Mini Bank Management System (Python & OOPs)

यह पायथन (Python) और **Object-Oriented Programming (Classes & Objects)** का उपयोग करके बनाया गया एक इंटरैक्टिव बैंकिंग एप्लीकेशन है। 

> ** Special Note:** यह मेरा **पहला प्रोग्रामिंग प्रोजेक्ट** है, जिसे मैंने पूरी तरह से अपने **मोबाइल फ़ोन** पर कोड और डिज़ाइन किया है! 
---

## मुख्य फीचर्स (Key Features)

* **Dual Entry Mode (दो शुरुआत विकल्प):**
  * **Option 1 (Demo Mode):** इसमें पहले से ही 10 डमी अकाउंट्स का डेटा (Maksudangarh Branch) मौजूद है। आप बिना कोई नया अकाउंट बनाए तुरंत मनी डिपॉजिट, विड्रॉ और अकाउंट हिस्ट्री टेस्ट कर सकते हैं।
  * **Option 2 (Custom Mode):** यहाँ आप खुद से नया अकाउंट होल्डर नाम और अंकों का एक यूनिक अकाउंट नंबर डालकर असीमित (Unlimited) अकाउंट्स बना सकते हैं।
* **Core Banking Operations:** रीयल-टाइम मनी ऐड (Deposit), मनी विड्रॉ (Withdrawal with insufficient balance check), करेंट बैलेंस चेक और साफ-सुथरी अकाउंट डिटेल्स देखना।
* **Interactive Transaction History:** आपके द्वारा किए गए हर डिपॉजिट और विड्रॉ की पूरी हिस्ट्री सीरियल नंबर और बचे हुए बैलेंस के साथ ट्रैक होती है।
* **Infinite Execution Loop:** यह सिस्टम तब तक लगातार चलता रहेगा जब तक यूजर खुद मेनू से 'Exit System' (Option 8) चुनकर इसे बंद न कर दे।
* **Robust Error Handling:** इनपुट बॉक्स में गलत वैल्यू (जैसे नंबर की जगह टेक्स्ट डालना) या 0 से कम अमाउंट डालने पर कोड क्रैश नहीं होता, बल्कि सही निर्देश देता है।

##  तकनीक और टूल्स (Technologies Used)
* **Programming Language:** Python 3.x
* **Core Concepts:** Object-Oriented Programming (OOPs), Custom Methods, Exception Handling (`try-except`), Loops (`while`), Lists & Dictionaries.
* **Development Environment:** Coded and pushed entirely via Android Mobile Device.

##  इसे अपने फोन या कंप्यूटर पर कैसे चलाएं?

1. इस प्रोजेक्ट की `bank_system.py` फ़ाइल को डाउनलोड करें।
